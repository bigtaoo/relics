# 00 · 项目定位

> 来源：2026-10-05 设计讨论汇总。这里只保留已经定下来的部分，待定项见文末。

## 一句话

**每一场输赢都看得懂的 8 人自走棋。** 单局 30 分钟以上：前期读牌、转型，后期终极阵容成型后实现逆转。

## 核心体验

- 准备阶段与战斗阶段分离，战斗中玩家没有任何输入。
- **单场战斗分阶段，不同定位在不同阶段强**：这是本作的差异点。同类产品大多只做到「位置决定数值」，缺少时间这个维度。
  - 远程：预备阶段尽量多杀敌，否则到决战没有优势。
  - 盾兵：前期挨打，撑过去之后就稳了。
  - 护盾流：需要凑齐组合，叠出大量护盾后发生质变。
- **核心乐趣是麻将式的「凑牌 → 胡牌」**：牌型凑齐时带来强烈的快感。最优解只有几套，大约十局才能凑出一次；技术体现在根据手牌决定往哪个方向做。详见 06。
- 新手练熟一套组合就能明显变强。

## 已定规则

| 项 | 值 |
|---|---|
| 人数 | 8 人同步 PvP，AI 补位 |
| 每轮 | 准备 20 秒 + 战斗 30 秒，约 35 轮 |
| 卡池 | 全局共享 |
| 时间延长卡 | 每人每局 1 张，所有人的当前准备时间同时延长 30 秒 |
| AI | 重点在阵容选型；可根据对手积分获得少量优势 |
| 第一版原型 | 完整复制三战「三国演弈」（ADR-006） |
| 表现 | 3D（ADR-005） |
| 技术 | Unity + C#，定点数确定性（ADR-001～004） |
| 平台 | iOS + Android + Windows PC（Steam），三端同服（ADR-009） |

## 待讨论的建议（来自讨论汇总）

- 次优阵容能稳定打进前列，最优阵容负责翻盘和碾压。
- 不同阵容之间有共用的核心棋子；「听牌」状态可见；明确的克制环；翻盘机制。
- AI 设计不同的性格；排位赛中慎用隐藏优势。
- 准备时间随轮次变化（前期短、后期长），在原型中验证。
