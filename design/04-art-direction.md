# 04 · 美术方向（3D）

> 决策：ADR-005。状态：讨论中。世界观尚未确定（不用三国题材）。

## 1. 可读性硬约束（与风格无关，必须做到）

1. **四种定位一眼能从轮廓分辨**：远程、盾、护盾、突袭。体型、武器、站姿差异要大，镜头拉远后也能看清。
2. **行动顺序条**：屏幕上始终显示「下一个行动的是谁」。三演的行动规则是确定的，必须让玩家看到。
3. **阶段提示**：从指挥切到决战时要有明显的转场，并且显示当前阶段哪类定位占优。
4. **大数字**：伤害、治疗、护盾值要大、颜色分开，暴击和爆发时额外强调。
5. **成型时刻**：缘分凑齐、终极阵容发动时，要有专门的演出，作为短视频素材（时长写进逻辑时间轴，见 01 §3.1）。

## 2. 镜头与棋盘

- 固定的俯视斜角镜头，三演和金铲铲都是这样。战斗中镜头可以做有限的推近和震屏，但不能遮挡行动顺序条。
- 8 人棋盘和观战切换要做无缝过渡。
- 2026-10-06 定：**准备阶段和战斗阶段用两个取景**，俯角和 FOV 相同，只平移和改距离。
  - 准备阶段：只框己方半场和备战席，放进 HUD（商店托盘、牌型面板、回合条）之外的空白区域。不这样做的话，商店托盘会挡住备战席。
  - 战斗阶段：整张桌面。开战时商店托盘收起，镜头约 0.9 秒平滑移到整桌，对手的棋子逐排落下。演示见 `art/ui/battle_start.gif`。

## 3. 风格候选

> 2026-10-06 定：**卡通风格化，不走写实**。保留「棋子 / 古器物材质 / 器物活过来」的概念，但造型和渲染都卡通化：大头、短粗四肢、简化形体、干净的手绘感配色，Unity 里用卡通渲染（toon shading + 描边）。即下表第 1 行的渲染方式 + 第 3 行的题材包装。第 1 轮写实青铜概念图作废，见 08 §1 进度。

| 方向 | 说明 | 优点 | 风险 |
|---|---|---|---|
| Q 版风格化（类似金铲铲 / 王者万象棋） | 大头小身体，卡通渲染 | 轮廓辨识度高，移动端负担小 | 与头部产品同质化 |
| 写实偏风格化的小比例士兵 | 类似 Total War 或策略游戏的小人 | 能体现「兵力、军团」的感觉 | 定位不容易一眼分清，成本更高 |
| 手办 / 棋子质感 | 角色像是放在棋盘上的精致棋子，有材质和底座 | 自走棋题材天然契合，演出时可以「棋子活过来」 | 风格需要反复打磨 |

## 4. 管线（待验证）

- 原型阶段：资源商店的占位模型，或者按定位区分的简单几何体，不阻塞玩法。
- 正式阶段可以考虑：
  - AI 生成概念图（沿用以往项目的提示词归档习惯）
  - AI 图生 3D（Tripo / Meshy / 混元 3D 等）做粗模，再人工修整拓扑
  - 统一的 Humanoid 骨骼，加上自动绑定和动作复用
  - 需要尽早做一次完整的小样验证：1 个角色走完「概念 → 模型 → 绑定 → 3 个动作 → 特效 → 进入 Unity」
- 以往的 2D 资产（.tao 骨骼、PNG 管线）不再沿用。

## 6. 世界观候选：山海经（讨论中）

### 优势

- 公版题材，没有授权问题，避开三国。
- 异兽的形体差异极大（多首、多足、鸟身、蛇身），**天然满足 §1 的轮廓辨识要求**。
- 3D 异兽比人形武将更能体现「表现力」，适合做成型演出和短视频素材。
- 五藏山经按「南、西、北、东、中」五方编排，可以直接对应麻将风牌，作为阵营和牌型的骨架（见 06 §4）。

### 风险

| 风险 | 说明 | 应对 |
|---|---|---|
| 题材同质化 | 国内卡牌、放置、MMO 已大量使用山海经 | 差异化要放在**美术风格**上，不靠题材本身 |
| 非人形骨骼成本 | 四足、鸟、蛇、多首无法复用 §4 的 Humanoid 骨骼和动作 | 限定为少数几个骨骼家族（人形 / 四足 / 飞禽 / 蛇龙），同家族共用动作 |
| 与三战机制的映射 | 三战是「武将带兵」，有兵力、兵种 | 兵力 → 生命或元气；兵种 → 形态家族；第一阶段先换名，不改机制 |
| 海外认知度低 | 外国玩家不熟悉 | 视觉奇观本身有吸引力；文案以「东方神话生物」为卖点 |

### 与 §3 风格的组合建议

**山海经 × 手办 / 棋子质感**：棋子做成陶俑、青铜器、玉雕、鎏金这类古器物质感，战斗时「器物活过来」。

- **材质 = 费用档位**：例如陶 → 青铜 → 玉 → 金，一眼可以读出稀有度。陶用灰陶（2026-10-06 改，原来的红陶和活体态、敌方红色底座撞色）。
- **只有成型的棋子活过来**（2026-10-06 定）：凑成牌型（胡）的棋子在成型演出里变成活体态，之后一直是活体；没成型的棋子始终是器物态，战斗中照样走动和攻击，但保持档位材质。
  - 这样战斗中能同时读出两件事：没成型的看材质知道档位，活体的就是成型的牌型。
  - 「活过来」成了胡牌的奖励，跟 06 的「兑现」直接挂钩。
- **棋子任何阶段都要在动**（2026-10-06 定）：器物态也一样播待机，不做静止的雕像。待机动作的幅度要在整桌镜头下也看得出来：呼吸起伏、左右重心、转头张望、前爪点地、尾巴摆动和开合，4 秒一循环。相邻棋子错开相位、速度有 ±10% 浮动，整盘不会同步摆动。器物和活体只靠材质区分。
- **棋盘 = 山海舆图**：古地图风格的棋盘，五方阵营各有地貌。
- 与常见的 Q 版、二次元山海经产品在视觉上明显区分。
- 需要尽早用 1 只四足异兽做 §4 的管线验证，确认非人形骨骼的成本。
